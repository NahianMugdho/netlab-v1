IPv6 ও MAC Address

থিওরি, visual demo, লিখিত অনুশীলন এবং MCQ। নিচের অনুশীলনে উত্তর লিখে সংরক্ষণ করতে পারবে।

১. IPv6 কী?

IPv6 হলো Internet Protocol-এর 128-bit address format। IPv4-এর 32-bit address space-এর তুলনায় IPv6-এ অনেক বড় address space রয়েছে। IPv6 address সাধারণত আটটি 16-bit hexadecimal group-এ লেখা হয়, প্রতিটি group colon (:) দিয়ে আলাদা।

উদাহরণ

2001:0db8:0000:0000:0000:ff00:0042:8329

শুরুতে থাকা zero বাদ দেওয়া যায় এবং ধারাবাহিক এক বা একাধিক শূন্য group একবার :: দিয়ে সংকুচিত করা যায়। একই address-এ :: সর্বোচ্চ একবার ব্যবহার করা যায়।

সংকুচিত রূপ: 2001:db8::ff00:42:8329

IPv6 group animation

আটটি group-ই 16-bit; মোট 128 bit।

২. IPv6 address-এর গুরুত্বপূর্ণ ধরন

  • Global Unicast: সাধারণত বিশ্বব্যাপী routable address; প্রচলিত range 2000::/3।
  • Link-local: একই local link-এ যোগাযোগে ব্যবহৃত; fe80::/10। Router সাধারণত link-local packet অন্য link-এ forward করে না।
  • Loopback: ::1 — নিজের host-কে নির্দেশ করে।
  • Unspecified: :: — নির্দিষ্ট address নেই বোঝায়; source হিসেবে বিশেষ পরিস্থিতিতে ব্যবহৃত হয়।
  • Multicast: ff00::/8। IPv6-এ IPv4-এর মতো broadcast নেই; multicast ও anycast ব্যবহার হয়।
  • Documentation: 2001:db8::/32 — উদাহরণ/ডকুমেন্টেশনের জন্য সংরক্ষিত।

IPv6 subnet-এ LAN-এর জন্য /64 বহুল ব্যবহৃত। IPv6-এ IPv4-এর মতো network/broadcast address বাদ দিয়ে usable host গোনা সাধারণ নিয়ম নয়।

৩. IPv6 address সংক্ষিপ্ত করার নিয়ম

  1. প্রতিটি hexadecimal group-এর বাম পাশের leading zero বাদ দেওয়া যায়: 0db8 → db8, 0042 → 42।
  2. একটানা শূন্য group-গুলোর দীর্ঘতম ধারাকে একবার :: করা যায়।
  3. :: একাধিকবার ব্যবহার করা যায় না, কারণ তখন বাদ পড়া group-এর সংখ্যা অস্পষ্ট হবে।

পূর্ণ: 2001:0db8:0000:0000:0000:0000:0000:0001

সংক্ষিপ্ত: 2001:db8::1

৪. MAC Address কী?

MAC (Media Access Control) address হলো data-link layer-এ local network interface শনাক্ত করতে ব্যবহৃত link-layer address। Ethernet MAC address সাধারণত 48-bit বা 6 byte; hexadecimal-এ লেখা হয়।

উদাহরণ: 3C:52:82:AB:19:7F

৬টি hexadecimal octet × ৮ bit = ৪৮ bit। প্রতিটি hex digit ৪ bit বোঝায়, তাই ১২টি hex digit = ৪৮ bit।

MAC address সাধারণত একই Layer-2 network-এর frame delivery-তে ব্যবহৃত হয়; router অন্য network-এ পাঠানোর সময় Layer-2 frame বদলে দেয়, কিন্তু IP packet-এর destination IP সাধারণত end host-এর থাকে।

Unicast, multicast ও broadcast MAC

  • Unicast: একটি interface-কে নির্দেশ করে।
  • Multicast: একটি group-এর interface-গুলোর জন্য।
  • Broadcast: Ethernet-এ FF:FF:FF:FF:FF:FF — local Layer-2 broadcast domain-এ পৌঁছায়।
  • MAC-এর প্রথম octet-এর least significant bit (I/G bit) 0 হলে সাধারণত individual/unicast, 1 হলে group/multicast।
  • প্রথম octet-এর U/L bit locally administered বনাম universally administered address বোঝাতে ব্যবহৃত হয়।

৫. IPv6 ও MAC-এর সম্পর্ক: Neighbor Discovery

IPv6 local link-এ প্রতিবেশী node-এর link-layer address খুঁজতে Neighbor Discovery Protocol (NDP) ব্যবহার করে। IPv4-এ সাধারণত ARP ব্যবহৃত হয়; IPv6-এ ARP ব্যবহার হয় না। IPv6 router discovery এবং Duplicate Address Detection-এও NDP ভূমিকা রাখে।
