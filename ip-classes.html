IPv4 Fundamentals

IP Address Class A, B, C, D, E

Classful IPv4 addressing-এর রেঞ্জ, প্রথম বিট, ডিফল্ট mask, ব্যবহার ও বিশেষ address এক জায়গায়। ফোনে টেবিল দেখতে পাশের দিকে স্ক্রল করতে পারবে।

Class A — প্রথম bit 0

Classful নিয়মে প্রথম octet-এর মান 1–126; default subnet mask 255.0.0.0 (/8)। প্রথম 8 bit network অংশ, বাকি 24 bit host অংশ। একটি /8-এ মোট 16,777,216 address থাকে; প্রচলিত subnet-এ network ও broadcast বাদে 16,777,214 usable host address হতে পারে।

উদাহরণ: 10.20.30.40 ঐতিহাসিক classful নিয়মে Class A। তবে বর্তমানে subnet mask/prefix না জানলে শুধু class দেখে আসল network boundary নিশ্চিত করা যায় না।

Class B — প্রথম দুই bit 10

প্রথম octet 128–191। Default mask 255.255.0.0 (/16); classful network অংশ 16 bit এবং host অংশ 16 bit। /16 block-এ 65,536 address, সাধারণভাবে 65,534 usable host address হতে পারে।

উদাহরণ: 172.20.5.10 ঐতিহাসিক classful নিয়মে Class B।

Class C — প্রথম তিন bit 110

প্রথম octet 192–223। Default mask 255.255.255.0 (/24); classful network অংশ 24 bit এবং host অংশ 8 bit। /24 block-এ 256 address, সাধারণভাবে 254 usable host address হতে পারে।

উদাহরণ: 192.168.1.25 ঐতিহাসিক classful নিয়মে Class C।

Class D — Multicast

224.0.0.0 থেকে 239.255.255.255 পর্যন্ত। এগুলো একটি নির্দিষ্ট host-কে নয়, multicast group-কে লক্ষ্য করে ব্যবহৃত হয়। Class A/B/C-এর মতো network/host ভাগ ও default subnet mask নেই। উদাহরণ: 224.0.0.1 — all-hosts multicast group-এর একটি পরিচিত address।

Class E — Reserved / Experimental

240.0.0.0 থেকে 255.255.255.255 পর্যন্ত range-কে ঐতিহাসিকভাবে Class E/reserved বলা হয়। সাধারণ end-host unicast addressing-এর জন্য ব্যবহার করা হয় না। মনে রাখবে, 255.255.255.255 হলো limited broadcast address এবং 127.0.0.1 হলো loopback address।

Classful বনাম CIDR — খুব জরুরি

Class A/B/C ও তাদের default /8, /16, /24 mask হলো ঐতিহাসিক classful addressing ধারণা। আধুনিক নেটওয়ার্কে CIDR ব্যবহার করা হয়—যেমন 192.168.10.0/27। তাই বাস্তব subnet বের করতে IP address-এর সঙ্গে দেওয়া prefix/subnet mask ব্যবহার করবে; শুধু A/B/C class থেকে সিদ্ধান্ত নেবে না।
