Subnetting বুঝে ফেলো

এগুলো ধারণা বোঝানোর animation; exercise-এর উত্তর PDF-এর terminology ও solution section অনুযায়ী রাখা হয়েছে।

১. IPv4 address = 32 bits

IPv4 address-এ ৪টি octet থাকে; প্রতিটি octet ৮ bit। Prefix length বলে প্রথম কত bit network অংশ হিসেবে ব্যবহৃত হবে।

Network bits: 24Host bits: 8Address count: 256

নীল = network bits, কমলা = host bits। Prefix বদলালে bit ভাগ বদলাতে দেখবে।

২. Subnet block-এর আকার

প্রতি subnet-এর মোট address সংখ্যা হলো 2^(32-prefix)। সাধারণ IPv4 subnet-এ network ও broadcast address usable host নয়।

৪. VLSM-এ বড় subnet আগে কেন?

প্রথমে সবচেয়ে বেশি host প্রয়োজন এমন network-কে সবচেয়ে বড় উপযুক্ত block দাও; তারপর ছোট block-গুলো পরের aligned boundary-তে বসাও। এতে block overlap ও “address hole” কমে।
