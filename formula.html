সব সূত্র এক জায়গায়

n = prefix length (CIDR), h = host bits = 32 − n। প্রতিটি সূত্রের নিচে ছোট উদাহরণ আছে।

১. মৌলিক

Binary bit-এর মান (এক octet)

128 · 64 · 32 · 16 · 8 · 4 · 2 · 1

Decimal → binary: বড় মান থেকে বিয়োগ করে যাও। উদা: 77 = 64+8+4+1 = 01001101

IPv4 ও IPv6 আকার

IPv4 = 32 bit = 4 octet · IPv6 = 128 bit = 8 group × 16 bit

মোট IPv4 address = 2³² = 4,294,967,296

Prefix ও mask-এর সম্পর্ক

/n ⇒ প্রথম n bit = 1 (network), বাকি 32−n bit = 0 (host)

২. Subnet Mask

Mask octet-এর সম্ভাব্য মান

1-এর সংখ্যা12345678
মান128192224240248252254255

CIDR → Mask

n = 8·k + r ⇒ প্রথম k octet = 255, পরের octet = উপরের টেবিলের r-তম মান, বাকি = 0

উদা: /26 → 26 = 8·3 + 2 → 255.255.255.192

Mask → CIDR

n = mask-এ মোট 1-এর সংখ্যা

উদা: 255.255.240.0 → 8+8+4 = /20

Wildcard mask

Wildcard = 255.255.255.255 − Mask

উদা: Mask 255.255.255.192 → Wildcard 0.0.0.63

৩. Block ও Host সংখ্যা

Block-এর মোট address

Total = 2h = 232−n

উদা: /26 → 2⁶ = 64

ব্যবহারযোগ্য Host

Usable hosts = 2h − 2

(−2 = network address + broadcast address)। উদা: /26 → 64 − 2 = 62

Block size (interesting octet)

Block size = 256 − (interesting octet-এর mask মান)

উদা: mask 255.255.255.192 → 256 − 192 = 64

প্রয়োজনীয় Host bit

ন্যূনতম h যাতে 2h − 2 ≥ H (দরকারি host) ⇒ n = 32 − h

উদা: 100 host → h = 7 (126 ≥ 100) → /25

Network address

Network = IP AND Mask

Broadcast address

Broadcast = Network OR Wildcard = Network + 2h − 1

Host range

First host = Network + 1 · Last host = Broadcast − 1

উদাহরণ: 192.168.10.77/26

Block = 64 → network = 192.168.10.64 → broadcast = 192.168.10.127 → host range = .65 থেকে .126 → usable = 62

৪. Subnetting (fixed length)

Borrowed bit (s)

s = নতুন prefix − পুরনো prefix

Subnet সংখ্যা

Subnets = 2s

উদা: /24 থেকে /27 → s = 3 → 8 subnet

প্রতি subnet-এ host

Hosts/subnet = 232−নতুন n − 2

উদা: /27 → 30 host

কয়টা subnet লাগলে কত bit ধার করবে

ন্যূনতম s যাতে 2s ≥ দরকারি subnet সংখ্যা

Subnet-গুলোর শুরু

k-তম subnet-এর network = Base + k × Block size (k = 0, 1, 2…)

৫. VLSM

নিয়ম

১) বড় host চাহিদা আগে সাজাও ২) প্রতিটির জন্য h বের করো ৩) বড় block আগে বসাও, পরেরটা আগেরটার broadcast + 1 থেকে

Next network

Next network = আগের Broadcast + 1 = আগের Network + 2h

Point-to-point link

2 host দরকার ⇒ h = 2 ⇒ /30

Alignment শর্ত

Network address অবশ্যই block size-এর গুণিতক হতে হবে

৬. Supernetting / Route Aggregation

নতুন prefix

New n = n − log₂(k) (k = একত্র করা network সংখ্যা)

উদা: 4টি /24 → /22

একত্র করার শর্ত

k = 2-এর power · network গুলো পরপর (contiguous) · প্রথম network supernet block-এ aligned

Common prefix পদ্ধতি

সব address binary করো → বাঁ দিক থেকে যতগুলো bit সবার এক, সেটাই new n

৮. IPv6

গঠন

128 bit = 8 group × 16 bit (প্রতি group 4 hex digit)

সংক্ষেপ করার নিয়ম

১) group-এর শুরুর 0 বাদ দাও ২) পরপর all-zero group একবারই :: দিয়ে বদলাও

উদা: 2001:0db8:0000:0000:0000:0000:0000:0001 → 2001:db8::1

Subnet সংখ্যা

/n prefix থেকে /64 subnet = 264 − n

উদা: /48 → 2¹⁶ = 65,536 টি /64

Address সংখ্যা

/n block-এ মোট address = 2128 − n

গুরুত্বপূর্ণ prefix

::1/128 Loopback · fe80::/10 Link-local · fc00::/7 Unique local · 2000::/3 Global unicast · ff00::/8 Multicast

৯. MAC Address ও EUI-64

গঠন

MAC = 48 bit = OUI (24 bit) + NIC-specific (24 bit)

MAC → EUI-64 (Interface ID)

১) MAC-কে মাঝখানে ভাগ করো (24 + 24) ২) মাঝে FFFE বসাও ৩) প্রথম byte-এর ৭ম bit (U/L) উল্টে দাও

উদা: 00:1A:2B:3C:4D:5E → 021A:2BFF:FE3C:4D5E (00 → 02) → Link-local: fe80::21a:2bff:fe3c:4d5e

Unicast / Multicast

প্রথম byte-এর সর্বনিম্ন bit: 0 = Unicast, 1 = Multicast; ff:ff:ff:ff:ff:ff = Broadcast

১০. দ্রুত সমাধানের ধাপ

Network / Broadcast / Host বের করা

n থেকে mask → interesting octet খুঁজে block size → IP-এর মান ছাড়িয়ে না যাওয়া সবচেয়ে বড় গুণিতক = network → +block−1 = broadcast

দুটি IP একই network-এ কি না

IP₁ AND Mask = IP₂ AND Mask ⇒ একই network

Valid host address কি না

Host ≠ Network address এবং Host ≠ Broadcast address
